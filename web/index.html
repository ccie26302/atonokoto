あとのこと

何があるかを描く。誰に渡すかを塗る。いなくなったら、そのとおりに。

ネットの契約や写真、アカウントを、あなたに何かあったとき「家族に渡す」か「止める」かを決めておく場所です。決めたあとは何もしなくていい。毎日こちらが、あなたの Google アカウントの動きを静かに見ています。

まず架空の例を見る自分の分をつくる（Google でログイン）審査用アカウントで入る ログインで求めるのは読み取りだけです。メールの既読と送信の日時、注文や予約の通知、Drive の活動、予定の変更、YouTube の高評価。件名や本文は見ません。受信箱の本文を読むのは、あなたが「棚卸し」を押したときの一回だけです。

何かあったとき、どうなるか

見張りは裏であなたの Google アカウントの動きだけを追います。あとのことへのログインは合図にしません。段階ごとの日数は下限で、短くなることはありません。

    どの段階でも、あなたの動きが見えたら最初に戻ります。確認者の誰かが「連絡が取れた」と答えても戻ります。実行の前には、あなた宛てに最後の通知を送って 7 日待ちます。

    保険として: Google の「アカウント無効化管理ツール」の信頼できる連絡先に あとのこと を入れておくと、上の見張りが全部止まっていても、Google の通知（最短 3 か月）で「沈黙 60 日」の段階に入ります。

    封印は、承認されたコードの中でしか開かない
    
    
    審査員向け。架空の山田太郎が預けた Netflix の資格情報（ブラウザで KMS の公開鍵で封印済み）を、本物の Confidential Space の VM を起こして開け、執行します。5 分ほどかかります。30 分に 1 回だけ。復号を許されているのは、いま動いている執行コードの image digest ひとつです。Cloud Run 側のサービスアカウントで同じ復号を試すと PERMISSION_DENIED になります（実測済み）。

    審査員向け。架空の山田太郎について、沈黙から執行までを時間を圧縮して通します。82 日が数秒になります。本物のアカウントには触りません。
    
    
    
      
    
      
  
      

  
      
    
      もしものとき、誰に連絡が行くか
      
    
      沈黙が 60 日続いたら、ここに登録した確認者に連絡します。2 人以上が「本人と連絡が取れない」と答えて初めて、遺志の執行が始まります。確認者は決めるだけで、何を渡すか・消すかには関われません。
